## How to Generate an API Key for OpenClaw (OpenAI)

To generate an API key for OpenClaw (OpenAI), follow these steps:

1. Go to [https://platform.openai.com](https://platform.openai.com) and sign in (or create a free account).
2. Click on your profile icon in the top-right corner and select **"API keys"**, or navigate directly to [https://platform.openai.com/api-keys](https://platform.openai.com/api-keys).
3. Click **"Create new secret key"**.
4. Give your key a name (optional) and click **"Create secret key"**.
5. **Copy your key immediately** — it will only be shown once. Store it somewhere safe (e.g., a `.env` file).

### Using your API key

Set your API key as an environment variable:

```bash
export OPENAI_API_KEY="your-api-key-here"
```

Or add it to a `.env` file in your project:

```
OPENAI_API_KEY=your-api-key-here
```

> ⚠️ Never commit your API key to a public repository.
